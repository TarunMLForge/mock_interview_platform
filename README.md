# mock_interview_platform
An enterprise-ready, $0-cost AI Mock Interview Simulator designed to help job seekers master technical interviews across all major IT fields—including MERN Stack, Machine Learning, DevOps, Cloud, Data Engineering, and Cybersecurity. Powered by Next.js 14, FastAPI, Groq API (LLaMA 3 70B), and Supabase, the platform conducts realtime voice interviews
